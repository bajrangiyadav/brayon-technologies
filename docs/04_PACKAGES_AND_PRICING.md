## 6. Standard Payment Milestone Rules

### For Standard Projects (Under ₹1 Lakh):
- **50% Advance:** Upon SOW signing to commence development.
- **50% Final Delivery:** After UAT demo approval, prior to production server deployment.

### For Mid & Large Projects (Above ₹1 Lakh):
- **30% Advance:** Project Initiation & UI Architecture.
- **30% Milestone 1:** Alpha Release (Frontend + Core API integration demo).
- **30% Milestone 2:** Beta Release & User Acceptance Testing (UAT).
- **10% Production Launch:** Production go-live, code repository handover & DNS propagation.
